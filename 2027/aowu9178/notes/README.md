## 第一次培训课
### 1.Linux
- `~` 为当前用户的家目录
- `.` 为当前目录
- `..` 为上一级
- `/home/user` 用户文件
- `/etc` 系统配置
- `/usr` 程序与库
- `/var` 日志等可变数据
- `/dev` 设备文件

### 2.Vim && Shell
**终端输入命令，由Shell解释，再交给程序运行**
-Shell命令结构`命令 [选项] [参数]`

- **命令**
- `pwd` 显示当前目录
- `ls` 列出目录内容
- `cd 目录` 进入指定目录
- `cd ..`返回上一级
- `cd ~`返回家目录
- `mkdir -p` 创建目录允许补全父目录
- `touch` 创建空文集/更新时间
- `cp` 复制文件
- `mv` 移动或重命名
- `rm` 删除文件 ***注意！rm通常不进回收站，删除前先确认路径和文件名！！！***
- `cat/less` 直接查看/分页查看
